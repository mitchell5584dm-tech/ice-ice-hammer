# Homepage sample songs

Put real tracks made in the studio in this folder (mp3, wav, ogg or m4a) and list them in
`manifest.json`. The "Made in the studio" section on the homepage appears only when at least one
track is listed.

```json
{
  "tracks": [
    {
      "file": "my-song.mp3",
      "title": "Track name",
      "style": "hard trap, female vocal",
      "model": "MiniMax",
      "lyrics": "The exact lyric that produced it"
    }
  ]
}
```

Only use songs you generated yourself and are entitled to publish.
